# 🛡️ Insurance Analytics Dashboard

An interactive Power BI dashboard designed to monitor insurance performance, track key KPIs (e.g., Claim Ratio, Premium Growth), and identify operational risk trends.

## 📊 Dashboard Preview
![Dashboard Preview](https://github.com/rehamdata/Insurance-Analytics-Dashboard/blob/main/Insurance_dashboard_screenshot.png)

## 🚀 Key Features
- **KPI Monitoring:** Tracks essential insurance metrics such as Claim Ratio and Premium Growth.
- **Comparative Analysis:** Facilitates performance comparison across different policy segments.
- **Data Integrity:** Rigorous data cleaning processes were applied to ensure accurate insights.
- **Advanced DAX:** Implemented complex measures to calculate insurance-specific calculations.

## 🛠️ Tech Stack & Tools
- **Business Intelligence:** Power BI Desktop
- **Data Modeling & Analytics:** DAX (Data Analysis Expressions)
- **UI/UX Design:** Minimalist Dashboard Design with customized themes, borders, and shadows.
